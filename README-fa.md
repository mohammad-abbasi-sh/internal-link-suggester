# internal-link-suggester — توضیحات فارسی

**پیشنهاد لینک داخلی از روی سایت‌مپ — با TF-IDF، بدون هیچ وابستگی.**

```bash
python ils.py --sitemap https://example.com/sitemap.xml
python ils.py --dir ./site-html --base-url https://example.com --md -o report.md
```

فقط پایتون ۳٫۱۰+ و کتابخانه استاندارد؛ بدون `pip install`، بدون API key.

## چه می‌کند؟

لینک داخلی یکی از ارزان‌ترین بردهای سئوی on-page است — و یکی از
پُرغفلت‌ترین‌ها، چون هیچ‌کس حوصله خواندن ۵۰۰ صفحه را ندارد تا بفهمد چه
چیزی به چه چیزی لینک بدهد. این ابزار خواندن را انجام می‌دهد:

1. **جمع‌آوری صفحات** — از `sitemap.xml` (ایندکس سایت‌مپ هم دنبال می‌شود)
   یا از پوشه‌ای از فایل‌های `.html` محلی.
2. **استخراج متن** — عنوان (با وزن دوبرابر)، هدینگ‌ها و متن بدنه؛
   ناوبری، فوتر، اسکریپت و استایل نادیده گرفته می‌شوند.
3. **رتبه‌بندی با شباهت کسینوسی TF-IDF** — همان وزن‌دهی پیش‌فرض
   scikit-learn، بازپیاده‌سازی‌شده با کتابخانه استاندارد.
4. **پیشنهاد انکرِ موجود** — انکرِ هر صفحه مقصد از پررنگ‌ترین اصطلاحات
   آن صفحه انتخاب می‌شود که در صفحه مبدأ هم آمده‌اند؛ پس لینک را بدون
   بازنویسی پاراگراف می‌توان اضافه کرد.
5. **پیدا کردن صفحات یتیم (orphan)** — صفحه‌هایی که هیچ صفحه دیگری به‌طور
   طبیعی به آن‌ها لینک نمی‌دهد.

دو چیز را عمداً پیشنهاد **نمی‌دهد**: صفحات نزدیک‌به‌تکراری (شباهت ≥
۰٫۹۵ — مشکل canonicalization است، نه لینک‌دهی) و صفحات نامرتبط (زیر
آستانه `--min-score`).

متن فارسی مستقیم پشتیبانی می‌شود: ی/ک عربی به فارسی نرمال می‌شوند و
لیست stopword فارسی اعمال می‌شود.

## مثال — اجرای واقعی روی سایت دمو

سایت دمو در `examples/demo-site/` شامل ۸ صفحه کوچک است: ۷ صفحه درباره
دم‌آوری قهوه در خانه و ۱ صفحه درباره ستاره‌شناسی. خروجی واقعی در
[`examples/demo-output.md`](examples/demo-output.md): **۸ صفحه، ۲۱
پیشنهاد، ۲ صفحه یتیم** — ستاره‌شناسی (نامرتبط، بیشترین شباهت ۰٫۰۲) و
راهنمای دانه قهوه (مرتبط ولی کم‌لینک: برای همه صفحات رتبه چهارم است و
با سقف top-3 انتخاب نمی‌شود — یک یافته واقعی).
